# Mr Worker

Mr Worker is a fullstack resume management application designed to help users create, organize, and export professional resumes.

The application allows users to manage structured resume data such as skills, work experience, education, and profile information, with support for future features like translations and PDF generation.

---

## 🚀 Tech Stack

### Backend
- Java
- Spring Boot (planned)
- REST API
- MySQL / PostgreSQL (planned)

### Frontend
- JavaScript
- HTML / CSS
